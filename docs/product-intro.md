# Questify 产品介绍

> **一句话定位**：把现实任务，变成角色成长

---

## 🎯 核心问题

传统 TodoList 的痛点：
- ✅ 任务只是"被勾掉"，缺乏即时反馈
- ✅ 完成后没有成就感，动力难以持续
- ✅ 任务优先级模糊，无法聚焦重点

---

## 💡 我们的推荐思路

### 思路一：游戏化激励，而非简单打钩

**传统做法**：任务完成 → 打钩 → 结束

**我们的做法**：任务完成 → 获得经验值 + 金币 + 属性成长 → 角色升级 → 解锁成就

> 核心理念：任务不是被勾掉，而是被转化成成长。

### 思路二：主线任务机制，聚焦每日重点

- 每天只能设置 **1 个主线任务**
- 主线任务奖励更高（额外 +20 EXP）
- 完成时有更强的视觉反馈

> 用"游戏主线"的概念，帮助用户识别和聚焦当天最重要的事。

### 思路三：轻 RPG，不做重游戏

**保留**：
- 等级、经验值、金币
- 四维属性（力量/智力/专注/活力）
- 称号和成就系统

**不做**：
- 复杂的战斗系统
- 社交/公会/PVP
- 抽卡/氪金机制

> 目标是增强"完成任务"的即时满足感，而非让用户沉迷游戏。

### 思路四：每日结算，强化成长闭环

- 每天结束时展示：今日完成任务数、获得 EXP/金币、属性提升
- 升级时有明确反馈（Level Up 动画）
- 解锁成就时有即时提示

> 让用户感受到"我不是只做了任务，而是我变强了"。

## 🎮 核心玩法设计

### 奖励规则

| 难度 | 经验值 | 金币 |
|------|--------|------|
| Easy | +20 | +5 |
| Medium | +50 | +10 |
| Hard | +100 | +20 |

### 任务标签 → 属性映射

| 标签 | 对应属性 |
|------|----------|
| 学习 | 智力 +1 |
| 工作 | 专注 +1 |
| 健身 | 活力 +1 |
| 生活 | 力量 +1 |

### 升级公式

```
下一级所需经验 = 当前等级 × 100
```

## 📊 产品差异化

| 对比维度 | 传统 TodoList | Questify |
|---------|---------------|----------|
| 完成反馈 | 打钩消失 | 奖励弹窗 + 经验增长 |
| 任务优先级 | 手动标记 | 主线任务机制 |
| 持续动力 | 无 | 等级/成就/称号系统 |
| 情感价值 | 工具感 | 角色成长的陪伴感 |

## 🎁 产品亮点总结

1. **游戏化任务管理**：用 RPG 成长机制替代简单打钩
2. **主线任务聚焦**：每日只有一个主线，强制聚焦重点
3. **即时 + 长期激励**：完成任务即时奖励，成就系统长期吸引
4. **成长可视化**：经验条、等级、属性，让进步看得见
5. **每日结算闭环**：强化"今天我变强了"的成就感
