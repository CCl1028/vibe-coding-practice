# 任务时效性与惩罚机制需求文档

## 1. 背景与目标

### 1.1 当前问题

- 任务面板没有"今日"与"过期"的区分，所有任务混在一起
- 用户缺乏当日完成任务的紧迫感
- 删除任务无成本，缺乏承诺感
- 任务可以无限拖延，无后果

### 1.2 设计目标

- 让用户清晰区分"今日任务"和"过期任务"
- 通过惩罚机制激励用户当天完成任务
- 通过正向奖励鼓励"今日全清"行为

---

## 2. 功能规格

### 2.1 任务状态定义

| 状态 | 定义 | 判断条件 |
|------|------|----------|
| 今日任务 | 创建于今天且未完成 | `createdAt.date === today && status !== DONE` |
| 过期任务 | 创建于今天之前且未完成 | `createdAt.date < today && status !== DONE` |
| 已完成 | 任务已完成 | `status === DONE` |

### 2.2 惩罚机制

#### 2.2.1 删除任务惩罚

用户删除任务时扣除金币：

| 场景 | 惩罚 |
|------|------|
| 删除今日普通任务 | -5 金币 |
| 删除今日主线任务 | -10 金币（5 + 5） |
| 删除过期普通任务 | -10 金币 |
| 删除过期主线任务 | -15 金币（10 + 5） |

**交互要求**：
- 删除前弹窗确认，显示将扣除的金币数量
- 若金币不足，仍可删除，金币扣至 0

#### 2.2.2 任务过期惩罚

任务从"今日"变为"过期"时，扣除经验值（一次性）：

| 任务类型 | 惩罚 |
|---------|------|
| 普通支线任务 | -10 EXP |
| 主线任务 | -20 EXP |

**触发时机**：
- 每日首次打开 App 时，检查昨日未完成任务
- 对每个新过期任务执行惩罚（只扣一次，标记 `overduePenaltyApplied = true`）

**交互要求**：
- 弹出"过期结算弹窗"，展示扣除明细
- 用户点击"我知道了"后关闭

#### 2.2.3 完成过期任务

| 操作 | 效果 |
|------|------|
| 完成过期任务 | 获得原奖励的 **50%**（向下取整） |

**说明**：
- 已扣除的过期惩罚不退还
- 鼓励用户处理过期任务，而非直接删除

### 2.3 正向激励

#### 2.3.1 今日全清奖励

| 条件 | 奖励 |
|------|------|
| 今日所有任务全部完成 | +20 金币 |

**触发时机**：
- 完成最后一个今日任务时立即触发
- 弹出庆祝动画 + 奖励提示

#### 2.3.2 主线达成奖励

| 条件 | 奖励 |
|------|------|
| 完成今日主线任务 | +10 金币 |

**说明**：
- 与今日全清奖励可叠加

## 3. 数据模型变更

### 3.1 Quest 模型新增字段

```typescript
interface Quest {
  // 现有字段...
  
  // 新增字段
  isOverdue: boolean;              // 是否已过期
  overduePenaltyApplied: boolean;  // 过期惩罚是否已执行
  penaltyAmount?: {                // 惩罚金额记录
    exp: number;
    gold: number;
  };
}
```

### 3.2 本地存储新增

```typescript
interface DailyCheckRecord {
  lastCheckDate: string;           // 上次检查日期 (YYYY-MM-DD)
  todayClearAchieved: boolean;     // 今日是否已达成全清
}
```

- [ ] 过期任务显示"完成可得 50%"提示

### Phase 2: 删除惩罚机制（0.5 天）

- [ ] 实现删除确认弹窗
- [ ] 删除时扣除金币逻辑
- [ ] 区分今日/过期/主线的不同惩罚

### Phase 3: 过期惩罚 + 结算弹窗（1 天）

- [ ] 实现每日首次打开检测逻辑

- [ ] 修改任务完成奖励计算逻辑

### Phase 5: 今日全清奖励（0.5 天）

- [ ] 检测今日任务全部完成
- [ ] 触发全清奖励 +20 金币
- [ ] 实现庆祝弹窗 UI
- [ ] 主线达成额外奖励 +10 金币

## 6. 验收标准

### 6.1 功能验收

- [ ] 任务面板正确分为"今日"和"过期"两个区域
- [ ] 删除任务弹出确认框并正确扣除金币
- [ ] 次日打开 App 弹出过期结算弹窗
- [ ] 过期任务完成只获得 50% 奖励
- [ ] 今日全清触发奖励和庆祝动画

### 6.2 边界情况

- [ ] 金币为 0 时删除任务，金币保持 0
- [ ] 同一个任务过期惩罚只执行一次
- [ ] 今日无任务时不触发全清奖励
- [ ] 跨时区场景正确判断"今日"
