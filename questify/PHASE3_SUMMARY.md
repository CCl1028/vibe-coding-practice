
### 5. 经验值系统 ⭐

**核心文件**：`src/lib/rewards.ts`

**等级公式**：
```typescript
// 下一级所需经验 = 当前等级 × 100
getExpForNextLevel(level) = level * 100

例如：
- Lv.1 → Lv.2: 需要 100 EXP
- Lv.2 → Lv.3: 需要 200 EXP
- Lv.5 → Lv.6: 需要 500 EXP
```

```typescript
interface DailyReward {
  date: string;              // 日期 YYYY-MM-DD
  totalExp: number;          // 今日获得经验

  totalStats: {              // 今日属性提升

    intelligence: number;
    focus: number;
    vitality: number;
```

**API 方法**：

## 🎨 动画技术栈

### Framer Motion 核心 API

**使用的动画属性**：
- `scale` - 缩放动画
- `opacity` - 透明度
- `x`, `y` - 位移
- `rotate` - 旋转
- `rotateY` - 3D 旋转
- `textShadow` - 文字阴影

**使用的动画类型**：
- `initial` - 初始状态
- `animate` - 目标状态
- `exit` - 退出状态
- `transition` - 过渡配置

**过渡类型**：
- `spring` - 弹簧动画（自然弹跳）
- `ease` - 缓动函数
- `duration` - 持续时间
- `delay` - 延迟时间
- `repeat` - 循环次数
