## Bug 修复

### 1. Web 端 Supabase 存储报错 "window is not defined"

- **文件**: `src/lib/supabase.ts`
- **修复**: 自定义存储适配器，Web 用 localStorage，Native 延迟导入 AsyncStorage

### 2. 创建任务按钮点击无反应 / 点击关闭弹窗

- **文件**: `app/(tabs)/quests.tsx`
- **根因**: Modal 中 Pressable 嵌套导致 Web 端事件冒泡问题
- **修复**: 将 modalOverlay 改为 View + 独立 TouchableOpacity 背景层分层架构，内容层与背景层为兄弟节点

### 3. 创建任务功能无法正常工作

- **文件**: `src/lib/services.ts`、`app/(tabs)/quests.tsx`
- **根因**: 
  1. `questService.create` 缺少 `updatedAt` 字段（数据库 NOT NULL 约束）
  2. Web 端 `Alert.alert` 不弹出提示，用户不知道未登录
- **修复**: 
  1. insert 时添加 `updatedAt: now`
  2. 使用 `Platform.OS === 'web' ? window.alert() : Alert.alert()` 兼容方案

### 4. 注册时 User 表插入 400 Bad Request

- **文件**: `src/lib/auth.tsx`、`app/login.tsx`
- **根因**:
  1. `signUp` 中插入 `User` 记录缺少 `updatedAt` 字段（NOT NULL 无默认值）
  2. Web 端 `Alert.alert` 错误信息不弹出，用户不知道失败原因
  3. 多次重试触发 Supabase auth 429 速率限制
- **修复**:
  1. insert 时添加 `updatedAt: now`
  2. 数据库迁移：为 `User.updatedAt` 列添加 `DEFAULT CURRENT_TIMESTAMP`
  3. `login.tsx` 中使用 Web 兼容的 `showAlert` 函数
  4. 增加 429 速率限制的友好错误提示

### 5. 登录方式改为邮箱验证码（OTP）

- **文件**: `src/lib/auth.tsx`、`app/login.tsx`
- **改动**:
  1. `auth.tsx` 新增 `sendOtp` 和 `verifyOtp` 方法，使用 Supabase `signInWithOtp` + `verifyOtp`
  2. `login.tsx` 完全重写为两步流程：
     - 第1步：输入邮箱 + 角色名（可选）→ 获取验证码
     - 第2步：输入 6 位验证码 → 验证并登录
  3. 特性：60 秒倒计时重发、粘贴验证码自动填充、退格键自动回退、填满自动提交
  4. 无需注册，新用户输入邮箱自动创建账号（`shouldCreateUser: true`）
  5. 去除了密码相关所有逻辑

### 6. 支持 Magic Link 登录 + OTP 验证码双模式

- **文件**: `src/lib/auth.tsx`、`app/login.tsx`
- **改动**:
  1. `auth.tsx` 在 useEffect 中添加 URL hash 解析，自动处理 Magic Link 回调登录
  2. `login.tsx` OTP 页面增加提示文案："点击邮件中的链接直接登录，或输入 6 位验证码"
  3. 兼容 Supabase 默认的 Magic Link 模式（无需修改邮件模板）
- **说明**: 
  - Supabase 默认发送 Magic Link 而非 6 位验证码
  - 如需发送 6 位验证码，需在 Supabase Dashboard → Authentication → Email Templates 中将 `{{ .ConfirmationURL }}` 替换为 `{{ .Token }}`

### 7. 改为本地存储模式（无需登录）

- **文件**: `src/lib/local-storage.ts`（新增）、所有页面文件
- **改动**:
  1. 新建 `local-storage.ts`，使用 AsyncStorage 实现完整的本地数据服务
     - `localCharacterService`: 角色数据（等级、经验、属性、金币）
     - `localQuestService`: 任务 CRUD + 完成追踪
     - `localAchievementService`: 成就进度自动更新
  2. 改造所有页面（index.tsx, quests.tsx, character.tsx, achievements.tsx）
     - 移除 `useAuth` 和 `user` 依赖
     - 使用本地存储服务替代 Supabase 服务
  3. 简化 `_layout.tsx`，移除 AuthProvider
  4. 应用直接进入主页，无需登录
- **特性**:
  - 完成任务自动更新成就进度（任务数、金币、连续天数等）
  - 升级自动更新称号
  - 角色页面可重置所有数据
  - 数据持久化在本地，关闭应用不丢失
